# Contributing

Thank you for your interest in Wemember.

- **Questions and bug reports:** open an issue in the repository concerned. Describe what you did, what you expected and what happened, and which client (for example Claude Code, Codex or Cursor) and version you used.
- **Security problems:** do not open an issue; follow the [security policy](SECURITY.md).
- **Pull requests:** please open an issue first so we can agree on the change. Keep pull requests small and focused, and describe how you tested them.

Check the license of each repository before reusing its code. Unless a repository says otherwise, its contents are not licensed for redistribution.
